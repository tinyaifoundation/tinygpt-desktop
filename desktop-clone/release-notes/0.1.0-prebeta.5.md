TinyGPT 0.1.0-prebeta.5 — Windows x64 pre-beta

An early testing build. Expect bugs and unfinished features.

First-run setup now uses the approved TinyGPT design: a rounded, frameless window, app artwork, a narrower progress bar, and simple “Installing TinyGPT” wording. Short status messages fade smoothly while setup runs. The window follows your system’s light/dark appearance and respects reduced-motion preferences. Progress reflects actual prepared and downloaded bytes.

Choose “Stop installation” below the progress bar to cancel. Downloaded parts are kept so reopening TinyGPT can continue. Successful setup now hands off to the main window and welcome without quitting the app.

Existing installations with matching local models reuse them. This setup window appears when model preparation takes long enough; it does not force a new model download on every update. A fresh installation needs approximately 2.48 GB of model data once, plus the app package and temporary working space.

Updates check on startup and every fifteen minutes while open. Use the update indicator above your sidebar profile or Settings > General > Updates. You choose when to download and restart; updates do not install automatically on quit. Compatible local update caches allow smaller downloads; a missing cache can require the complete app package.

This build remains unsigned by a verified Windows publisher while Azure signup is unresolved, so Windows may show a publisher or reputation warning. Updates still require metadata authenticated by TinyGPT’s pinned Ed25519 release key and matching file checksums. This authentication does not remove Windows warnings.

Pre-beta 2 users must install an updater-enabled build manually once. Windows x64 only; Mac remains deferred. Google publisher review remains pending. Conversations and memories remain local without application-level chat encryption; optional external providers receive the context sent to them. See https://tinygpt.org/privacy-policy.

Feedback: help@tinygpt.org. Include the version and reproduction steps, without passwords, API keys or private conversation content.
