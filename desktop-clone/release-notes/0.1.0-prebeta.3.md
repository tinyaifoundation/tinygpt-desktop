TinyGPT 0.1.0-prebeta.3 — Windows x64 pre-beta

An early testing build. Expect bugs and unfinished features.

A refreshed five-step welcome adds an immediate light/dark choice, optional TinyGPT Pro and OpenRouter setup, local profile and memory preferences, an optional animated Bot setup, and voice and starter ideas. Every step can be skipped; the included on-device AI remains available.

This release adds an update indicator above your sidebar profile. Click it to download a verified update, then choose Restart to update when your active work is finished. You can also check in Settings > General > Updates. Updates do not install automatically when you quit.

This pre-beta is unsigned by a verified Windows publisher, so Windows may show an unverified publisher or reputation warning. Azure signup is awaiting resolution. In-app updates authenticate TinyGPT's pinned Ed25519 release key and the downloaded files' checksums; altered or unauthenticated updates are rejected. This release-key verification is separate from Windows publisher signing.

The app and local models are now separate downloads. New installations download approximately 2.48 GB of included model data on first launch, with progress shown. Matching models from an earlier installation are reused where available. Once prepared, those model files remain on this computer across app updates. Models download again only if missing, changed or corrupt. A complete prepared local installation works offline; connected providers and tools still need internet.

App updates download changed blocks when possible. A missing update cache or incompatible package can require the complete app package; it does not normally require downloading unchanged models again. Setup and update reconstruction need temporary disk space.

The public source code is Apache-2.0 licensed, with separate notices for third-party code and model assets. The optional Satoshi font is excluded; existing Satoshi preferences use Figtree.

Google publisher review remains pending. Updates are for Windows x64 pre-beta; Mac downloads and Mac updating are not part of this release. Users of 0.1.0-prebeta.2 must manually install an updater-enabled build once.

Conversations and memories remain local without application-level chat encryption. Optional cloud models and connected services receive the context sent to them. See https://tinygpt.org/privacy-policy.

Feedback: help@tinygpt.org. Include the version and reproduction steps, without passwords, API keys or private conversation content.
