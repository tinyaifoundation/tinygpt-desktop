TinyGPT 0.1.0-prebeta.4 — Windows x64 pre-beta

An early testing build. Expect bugs and unfinished features.

Pre-beta update checks now run on startup and every fifteen minutes while the app is open. Pending notifications refresh when a newer build is available. Use the update indicator above your sidebar profile, or Settings > General > Updates. You choose when to download and restart; updates do not install automatically on quit.

This build also exercises the authenticated updater between real releases. Updates verify TinyGPT's pinned Ed25519 release key and the downloaded files' checksums. It remains unsigned by a verified Windows publisher while Azure signup is unresolved, so Windows may show a publisher or reputation warning. Release-key authentication is separate from Windows publisher signing.

The app and included models are separate. A fresh installation downloads approximately 2.48 GB of model data on first launch. Matching models from an earlier installation are reused where available and remain across app updates. Changed app blocks download when a compatible local update cache is available; a missing cache can require the full app package. Setup and reconstruction need temporary disk space.

Includes the refreshed five-step welcome: immediate light/dark choice, optional eligible-machine TinyGPT Pro and OpenRouter setup, local profile and memory preferences, optional Bot setup, and voice and starter ideas. Every welcome step can be skipped.

Users of 0.1.0-prebeta.2 must manually install an updater-enabled build once. Windows x64 only; Mac remains deferred. Google publisher review remains pending. Conversations and memories remain local without application-level chat encryption; optional external providers receive the context sent to them. See https://tinygpt.org/privacy-policy.

Feedback: help@tinygpt.org. Include the version and reproduction steps, without passwords, API keys or private conversation content.
