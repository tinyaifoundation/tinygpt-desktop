# TinyGPT onboarding artwork

The current direction uses one flat, sparse UI detail per screen with a vibrant gradient background. Avoid 3D objects, glass, ribbons, busy collages, perspective and decorative floating props. The public wordmark is live TinyGPT text without a trailing dot. Step counts and promotional footer notes are omitted.

Assets live in `src/renderer/assets/onboarding/`: companion-gradient.png, free-gradient.png, memories-gradient.png and work-gradient.png. They were generated with ImageGen from actual TinyGPT Chat, Work, Profile, Personalization and Voice screenshots captured in an isolated sample profile. Alex and the pictured sample prompts are fictional fixture content. None of the source references used private account content.

The four subjects are a private AI companion, free included local inference, optional profile name and local memories, and Work/coding/documents/voice. The generated UI is decorative illustration; interactive settings and navigation remain real application controls in the right panel. Preserve the distinction between local storage and excerpts sent to an optional cloud model. Free forever describes the included local model, not external provider charges.

For future changes, capture current UI with synthetic data, inspect the references before generation, and use the approved flat image style. Keep the subject clear at desktop and compact sizes. Run the onboarding UI smoke check to capture all four screens and verify image decoding, name persistence, memory-sharing preferences, skip/replay, voice preferences and starter drafts.
