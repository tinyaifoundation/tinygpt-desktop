# TinyGPT onboarding artwork

The current direction matches the website's Meet TinyGPT section: layered radial gradients, a white prompt bubble, and one crisp foreground UI card with restrained shadows. Avoid 3D objects, ribbons, busy collages, perspective and decorative floating props. The public wordmark is live TinyGPT text without a trailing dot. Step counts and promotional footer notes are omitted.

The artwork is rendered in `src/renderer/components/OnboardingShowcase.tsx` and `src/renderer/onboarding-showcase.css`, using the same gradient colors as the website's ShowcaseArtwork component. The five compositions show an idea conversation, the included local model, profile/memories, the real animated Bot avatar, and a coding task with documents/voice. Alex, the memory and the prompts are fictional sample content. Artwork has no interactive elements and is hidden from assistive reading. The older generated PNGs in `src/renderer/assets/onboarding/` are retained as previous design assets and are no longer imported by the onboarding.

The five subjects are a private AI companion with immediate theme choice, free included local inference with optional Pro/OpenRouter, optional profile name and local memories, a personal Bot, and Work/coding/documents/voice. The UI mockups are decorative illustration; interactive settings and navigation remain real application controls in the right panel. Preserve the distinction between local storage and excerpts sent to an optional cloud model. Free forever describes the included local model, not external provider charges.

For future changes, use current UI with synthetic data and keep the website's gradient/card treatment. Keep the subject clear at desktop and compact sizes. Review all five screens and verify name persistence, memory-sharing preferences, skip/replay, voice preferences and starter drafts when those behaviors change. Every optional setup has a later/skip path. The included model starts without welcome selection. Pro appears only after actual compatibility confirmation.
