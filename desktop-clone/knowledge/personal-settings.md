# Appearance, profile and notifications

Open Settings → Appearance to choose system, light or dark appearance and edit each theme's accent, background, foreground, contrast and translucency. Separate UI, content and code font settings control their typeface/weight; size and smoothing controls affect readability. Use Reduce motion to reduce animations or follow the system preference. Pointer cursors, app icon and diff markers have their own controls. Theme import/copy controls exchange supported TinyGPT theme JSON, not arbitrary executable themes.

## Change your profile

Open Settings → Profile, choose Edit, change first/last name or photo and save. The profile is local. A supplied name is also stored as a personal memory; control its availability in Personalization. Removing a photo and changing a name are separate operations. Profile activity panels show locally recorded usage such as token activity and most-used tools; they are not a provider billing invoice.

## Control notifications

Open Settings → Notifications. Pause alerts silences alerts and sounds while Activity continues updating. Choose desktop notifications, whether to notify only when away, message previews and unread dots. Individual event types include Chat replies, Work tasks, Bot replies/jobs, attention requests and problems/interruptions.

Enable sound, choose the TinyGPT chime or a supported custom WAV/MP3, set volume and preview it. Quiet hours pause alerts/sounds during the selected local-time interval. Test desktop notification checks delivery, but operating-system notification settings or focus modes may still suppress it. Message previews can expose a title and text on the screen; disable them if that is unwanted.

The Activity feed and unread indicators help find completed work or requests for attention. A notification is not independent proof of the correctness of a task's result; inspect its conversation, tool results and output files.

Each newly saved Bot message creates its own notification event, including messages sent while the Bot continues working and proactive updates. Empty typing placeholders do not notify, repeated updates do not duplicate a message, and finishing the run does not add an extra completion alert for the same message. Historical messages are not replayed as desktop alerts after restarting or dismissing notifications. Desktop alerts, paired-device delivery, quiet hours, away-only preferences and sound limits still apply. Chat and Work completion notifications remain per run.
