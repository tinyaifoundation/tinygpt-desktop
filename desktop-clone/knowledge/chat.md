# Chat, research and answers

Use Chat for questions, writing, research and supported tool tasks. Choose a connection and model, type your request, and attach relevant material using the composer. The selected model's tool and image capabilities affect what it can do. With tools disabled, the assistant can answer from supplied context but cannot claim to have browsed, edited files or contacted an account.

## Research a question

Ask for web research when current sources are needed. Search and page reading can run in the background. Source chips and citations connect an answer to its evidence. Open the cited source to inspect it. A cited passage can be incomplete or outdated; a search result alone does not establish the truth of an entire answer.

Interactive website work uses TinyGPT's browser tools. The user can watch browser work. Sign-in, verification, consent and sensitive input may require a handoff in the same tab. Complete the requested step, then let the task resume. Browser settings select the search engine, link destinations and privacy controls.

## Follow a reply

Local-model loading appears in the conversation's working history with a square refresh icon.

A Chat reply has one tool chain, one temporary progress message below it, and one answer area. A new progress message replaces the previous one as it streams. Starting another tool keeps the latest progress message in that position; it does not become the chain’s title or get folded into the tool disclosure. Expand the chain to inspect tools and thinking. Once the harness identifies the final answer, the temporary progress message disappears and the answer appears in its own area. Progress does not return when the reply completes or is reopened.

Streaming follows the provider’s answer/progress signals. Built-in thinking models retain their answer-boundary validation, so their final text can remain held until the model finishes cleanly. Text without a confirmed answer signal can be shown as temporary progress before promotion. The layout does not guess finality from wording, remove model checks, change tool permissions or replay actions. Work retains its chronological working history and nested Coding agent sections.

An answer can begin with a generated visual, such as a comparison table or chart, before any final text. That also hides temporary progress, including while the visual is being prepared. A later tool-only visual does not turn an earlier research update into answer text. The same display rules apply in the mobile companion.

## Manage a conversation

Use available message controls to copy, regenerate or export an answer. Find in conversation locates text in the current conversation; Search chats finds saved conversations. Branching/retrying follows the selected conversation history. TinyGPT may summarize older context to fit the model's window while preserving saved original messages. That does not give the model unlimited recall of every past detail.

## Ask about TinyGPT

Bundled product help explains this installed build's behavior and settings. The assistant can search it with search_help, including by article ID to read a full topic. Product-help passages are separate from personal memories. Ask for clarification if a feature's availability depends on your model, operating system, connection or permission. The assistant must distinguish general capability from access verified in this conversation.
